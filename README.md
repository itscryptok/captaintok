# Captain Tok (static clone)

Static clone of the Captain Tok site — AI news & investing blog, books, and consulting services.
Deployed as a free Render static site for captaintok.com.

Backend APIs (/api/*) are not available in this static build: blog posts, books,
checkout, digests, newsletter, and the /addy admin panel require the original backend.
The contact form works via Web3Forms.
